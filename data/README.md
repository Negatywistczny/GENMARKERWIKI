# `data/` (Dane Źródłowe i Raporty)

* **Status:** ⚪ `[OPCJONALNY]`

Katalog przeznaczony na pliki danych i generowane raporty:

- `raw/` — surowe pliki danych genotypowych (zrzuty CSV WGS / mikromacierzy).
- `reports/` — wygenerowane raporty genetyczne w formacie Markdown i HTML:
  - `markery/` — badania i research poszczególnych markerów.
  - `ryzyko/` — kompendia i bazy ryzyka poligenicznego.
  - `Raport-osobisty-genom-wiki.md` — główny raport całogenomowy.
